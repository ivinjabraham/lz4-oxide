# lz4-oxide Working Plan

This file tracks current status and remaining work. Architectural rationale is
in [DECISIONS.md](DECISIONS.md), compatibility traps are in
[PORTING.md](PORTING.md), and user-facing instructions are in
[README.md](README.md).

## Current Status

The library port is complete at the exported-symbol level:

- All 141 public symbols have implemented bodies.
- `make test` passes the complete unmodified upstream suite.
- `make abi-check` reports the same exported ABI as the pinned C archive.
- `make difftest` reports no divergence in its covered matrix.
- HC levels 1 through 12 are byte-identical through the block HC APIs.
- Benchmark results and environment metadata are generated by `bench/bench.py`.

These statements have different scopes. In particular, the differential matrix
does not cover malformed frame decoding or HC levels 3 and above through the
frame API. See [DECISIONS.md section 8](DECISIONS.md) for the complete
limitations table.

## Development Loop

For every codec change:

```sh
make difftest     # byte identity and covered rejection parity against C
make test         # complete unmodified upstream suite
```

Run the focused checks when changing ABI, build, or safety boundaries:

```sh
make abi-check
make provenance-check
make kickoff-verify
make unsafe-count
cargo test
```

Do not trust a green upstream suite without differential comparison. The suite
primarily checks round trips and checksums; it cannot detect wrong-but-valid
compressed bytes or a decoder rejecting malformed input at the wrong offset.

## Remaining Work

Ordered by behavioral impact, then performance impact.

1. Route frame compression levels 3 and above through the matching HC strategy.
   Extend `fuzz/framediff.c` with positive levels before changing the dispatch.
2. Add malformed and truncated frame-decompression differential coverage.
3. Fix the debug HC null-prefix slice construction so debug assertions and
   overflow checks can run under the upstream fuzzer.
4. Make advanced frame custom allocators own working buffers as required by the
   upstream contract, replacing internal `Vec` ownership with hook-allocated
   storage and offsets.
5. Port `LZ4_FAST_DEC_LOOP` for many-short-sequence workloads. Extend rejection
   sweeps across its 64-byte margin before enabling it.
6. Propagate non-default `LZ4_MEMORY_USAGE` consistently between C callers and
   Cargo builds.
7. Add generative malformed-frame fuzzing beyond the fixed differential matrix.
8. Build every Dockerfile target on a host with Docker.

Generated benchmark numbers belong in `bench/results.json`. Run
`bench/bench.py` after performance-sensitive changes rather than copying values
into planning or decision documents.

## Non-Negotiable Rules

- Never edit files under `upstream/`.
- Keep deterministic compressed output byte-identical to the pinned C library.
- Keep `unsafe` confined to `src/ffi.rs`.
- Preserve caller-allocated public layouts; never add Rust-owned containers to
  those types.
- Keep source and destination overlap legal where the C API permits it.
- Do not run `make gen-ffi` during normal development; it overwrites the
  implemented `src/ffi.rs`.
- Do not simplify the `C_SRCDIRS`, `LDLIBS`, CLI prebuild, or provenance logic
  without reviewing [README.md](README.md#how-it-fits-together).

## Setup

```sh
git submodule update --init --recursive
source "$HOME/.cargo/env"
make link-check
```

`LZ4_SRC=/path/to/lz4` may point builds at another checkout, but doing so
invalidates claims tied to the pinned commit, including `kickoff-verify` and the
committed ABI contract.

## Commands

| Command | Purpose |
|---|---|
| `make` | Build the release Rust library |
| `make link-check` | Build upstream test programs and check their primary `lz4.o` provenance |
| `make difftest` | Compare covered output and rejection behavior with C |
| `make test` | Run the complete upstream suite against Rust |
| `make test-quick` | Run upstream fuzzer and frame tests |
| `make test-reference` | Run the suite against the untouched C library |
| `make abi-check` | Compare exported symbols with the pinned ABI |
| `make provenance-check` | Check that each binary's primary `lz4.o` came from `cstub/` |
| `make kickoff-verify` | Verify the pinned upstream tree and kickoff hashes |
| `make unsafe-count` | Enforce the unsafe-code boundary |
| `cargo test` | Run Rust tests and checksum oracle checks |
| `bench/bench.py` | Rebuild, verify, benchmark, and regenerate structured results |
